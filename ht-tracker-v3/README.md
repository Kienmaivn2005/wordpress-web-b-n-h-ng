# HT-TRACKER PRO 3.0

## Tài khoản đăng nhập
Theme KHÔNG có một tài khoản/mật khẩu mặc định riêng. Nó dùng tài khoản WordPress.

Sau khi cài:
1. WP Admin → Người dùng → Thêm người dùng.
2. Tạo tài khoản và mật khẩu.
3. Nếu là tài khoản quản trị, chọn vai trò Quản trị viên.
4. Vào HT-TRACKER → Quản trị để tạo các tài khoản Lãnh đạo / Trưởng đơn vị / Chuyên viên.

## Vai trò
- Quản trị viên: quản lý tài khoản, văn bản, nhiệm vụ.
- Lãnh đạo: xem toàn bộ dữ liệu.
- Trưởng đơn vị: cập nhật nhiệm vụ thuộc phạm vi đơn vị.
- Chuyên viên: chỉ xem/cập nhật nhiệm vụ được giao.

## Database
- wp_ht_docs
- wp_ht_tasks
Dữ liệu dùng chung giữa các tài khoản WordPress.

## Lưu ý
Bản 3.0 thêm quản lý tài khoản và gán người phụ trách bằng user ID. Các đơn vị hiện có thể mở rộng thêm trường/quan hệ riêng nếu cần.
